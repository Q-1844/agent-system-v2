# 跨镜头衔接策略（shot-continuity）

## 先分类，再决策

四种衔接要求，决策路径不同，不要混用：

1. **动作连续**：本镜继续上一镜未完成的动作（同一动作的两段）。
2. **空间连续**：同一空间内的镜头变化（机位移动、景别变化）。
3. **身份保持**：同一角色跨镜出现（可跨空间、可切镜）。
4. **正常切镜**：电影式 hard cut（换场、时间跳跃、反应镜、插入镜）——
   **不是缺陷，不强制接力，不插桥**。

## 三层端点（先分清，再接力）

| 端点 | 含义 |
| --- | --- |
| 源素材物理尾帧 | 生成视频文件的最后一帧 |
| 候选剪辑区间的最后保留帧 | 建议裁切区间（trim 后）的出点帧 |
| 用户实际选用区间的最后保留帧 | 用户正式选版后的真实离开状态 |

规则：

- **动作接力依据实际保留片段的最后一张保留帧**，不是机械使用源视频物理
  尾帧。若源素材后部将被裁掉，接力规划用保留区间的出点状态。
- 抽帧来自最后一张实际保留的视频帧，不抽 trim_out 之后第一张被排除的帧。
- 记录：源素材版本、有效区间、抽帧时间或帧号、下一镜依赖关系——可追溯。
- 裁切变化影响已依赖原端点的下一镜时：先复核该依赖，不自动判其必然失效，
  也不假装依赖没有变化。未依赖该端点的镜头（独立首帧、正常切镜）不因前镜
  裁切而机械重做。
- 用户自行后期剪辑时：交付建议区间与所依据的端点；用户另选端点后，再复核
  受影响镜头。

## 同机位 vs 新机位

- **同机位动作延续**：上游端点合格时，可用其（保留区间的）尾帧起步
  （keyframe 首帧硬边界或 reference 语义参考，按槽位语义选）。
- **同一空间换机位**：**重建所需构图**并核对空间、轴线与人物位置——尾帧
  可以作为状态依据（谁在哪、持有什么），但**不能替代新机位的构图设计**。
  不机械把旧机位尾帧送进首帧槽然后期望模型自己换景别。
- 跨景别（远景→中近景等）：按目标景别重建首帧；上游远景尾帧作状态参考。

## 状态相等规则的适用边界

- "状态相等"只用于**确实延续的动作和状态**（同机位接力、连续动作两段）。
- 时间跳跃、换场：按剧本允许的状态变化核对（衣服、光线、道具位置可以合理
  变化），不要求物理尾态无条件相等。
- 换场镜的身份保持仍要核对（角色特征跨镜一致），与空间接力是两回事。

## 缺上游证据时

- 先读合法上游事实（上游镜头的 final_video、trace、保留区间记录、分镜
  expected_tail）。
- 动作连续任务若缺少必要状态证据（上游端点未审、版本过期、记录缺失）：
  **报告缺项**，请上游补审或补记录；不猜测、不悄悄改变叙事要求、不擅自把
  动作连续改成正常切镜来绕过缺证据。
- 上游重选新版本后：下游旧引用标记待复核——比较下游真实输入与新上游状态，
  合格镜可保留，过期引用不得沿用；不机械全重做，也不静默沿用。

## 起步方法菜单（每镜按端点质量与衔接要求自主选择）

| 方法 | 适用 | 注意 |
| --- | --- | --- |
| 合格尾帧作首帧硬边界 | 同机位动作延续、端点合格 | 仍须核对实际第 0 帧与中段 |
| 尾帧作语义参考（reference） | 状态延续但不锁首帧 | 身份不可读时避免单靠它 |
| 融合/重建首帧 | 换机位、跨景别、端点状态可用但构图不可用 | 尾帧作状态依据，构图按本镜设计 |
| Look 主导独立首帧 | 正常切镜、换场、端点已画错 | 写清剧情代价；身份由 Look 锚定 |
| keyframes 双帧桥 | 两端合格且必须连续过渡（窄判据） | 方法细节读关联技能 keyframes-bridge-repair |

方法选择本身就是被测试的决策：按本镜情况选，不为"看起来连续"强行接力，
也不为省事把该接的镜切成硬切。
