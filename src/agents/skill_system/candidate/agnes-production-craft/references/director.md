# 导演执行要点（references/director.md）

导演是本包的 primary_executor。逐镜执行以下纪律；与正式链共用的治理规则
（canonical、OCC、用户选版）不变。

## 逐镜决策顺序

1. 读上游事实：故事段、approved Look、场景/状态图、上游镜头的 final_video
   与保留区间记录。缺事实 → 报告缺项，不猜。
2. 定规划字段（SKILL.md §每镜规划 8 项），写入既有分镜字段。
3. 选首帧方法与参考（first-frame-image.md）；生成后过质量门。
4. 写视频提示词、选模式与时长（video-action-causality.md）；出站自检。
5. 提交后核对回执与文件真实时长。
6. 完整审片（repair-diagnosis.md 顺序）；产出三档结论。
7. 可保留 → 剪辑建议；关键节点错误 → 修根因。
8. 有下游依赖 → 先落"实际保留区间与离开状态"，再放行依赖镜。

## 审片记录字段（每镜留档）

题目与镜头 ID / 组别 / Skill 版本 / 实际模型与模式 / 提示词要点 / 参考资产
职责 / 素材真实时长 / 首次或第几次返工 / 源媒体版本 / 错误时间区间 / 必须
保留事件 / 建议剪辑区间 / 三档结论。

## 与装配的关系

- 装配发现问题反馈给制作方（导演自己修，或如实上报）——装配不因绑定 Skill
  获得修改他人 canonical 的权限。
- 交付给装配/用户的材料：全部源素材版本、建议入出点、接力端点依据、音频
  注意事项（裁切造成的关键音效错位要标注）。
