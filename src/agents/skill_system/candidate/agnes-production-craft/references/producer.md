# Producer 编排要点（references/producer.md）

Producer 是本包的 coordinator。按档编排，不代做专业判断。

## 编排纪律

1. 任务下达时把**素材时长政策**（≥8 秒、默认 10 秒）与"生成时长≠成片
   时长"一并写进目标；两组试验都一样。
2. 视频节点前置条件：首帧质量门已过；接力镜的上游端点已审。
3. 审查关口给用户的是**具体媒体 + 建议区间 + 需要用户判断的事项**，不是
   汇总性形容词。
4. 汇报口径用三档：原片整体合格 / 原片有错但可裁切得到合格片段 / 裁切仍
   不能完成剧情任务；不以平均分掩盖硬错误。
5. 修复候选未正式选用前，正式下游继续指向原选版；向用户报告时区分
   "修复完成"与"用户接受"。
6. 配额感知：视频按秒计费（Token Plan 500 秒/天口径）；技术失败的重试
   与画面不合格的重生分开统计并向用户如实汇报。
