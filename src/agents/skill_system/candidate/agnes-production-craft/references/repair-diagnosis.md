# 失败诊断与修复策略（repair-diagnosis）

## 修复顺序（先裁切判断，后根因修复）

```
1. 完整审片（先整段播放，再按关键动作/接触点/疑似错误补查帧）
2. 确认偏差的时间区间与重要性
3. 判断能否保留完整剧情区间（见 SKILL.md 可剪判定表）
   ├─ 能保留 → 交付具体剪辑建议（区间 + 理由 + 音频复核），保留源素材，记录原片错误
   └─ 不能保留 ↓
4. 定位最早偏差（第一处出错的层：输入资产 → 根帧/首帧 → 资源绑定 →
   视频过程 → 叙事尾态 → 剪辑接缝）
5. 改方法或重做相应素材（候选身份；不静默替换正式选版）
6. 比对：原问题是否修掉 + 是否引入新问题（重试后完整复查，不只看原问题）
7. 按既有用户选版机制进入正式链
```

关键身份、接触、交接和因果节点错误**必须修复**：不允许剪掉关键过程伪装
合格。主动作和结果分落在错误区间两侧时，单镜裁切不成立。

## 偏差严重度：范围 × 重要性

按固定类别（发型/配色）单维分级不够。同时评估：

- **范围**：一帧内的小点 / 一段内的局部 / 贯穿全段。
- **重要性**：是否识别性特征（标志性发型、关键道具主色、人物身份标志）、
  是否在必须保留的事件上。

识别性特征即使局部出错（如标志刘海的侧别、灯笼的主色）也可能是**重大
偏差**——因为它沿接力传播且观众靠它认人。非识别性、非关键事件上的局部
小偏差才可能是 minor。

## 保留合格部分

- 尾部有错误但前面已有合格结果 → 优先保留合格区间（给剪辑建议）。
- 尾帧偏差同样沿链传播且换种子无效（正式链实证）——接力前核对真实端点。
- 局部错误 ≠ 存在局部编辑接口：图像重绘后的"合格部分"必须重新核对
  （重绘可能改变未指定的区域）。
- 视频阶段对首帧缺陷有部分自愈力，但不能依赖；首帧不合格仍按首帧失败记录。

## 重试上限与换方法

- 同一方法最多 **2 次追加重试**（首次生成 + 2 次追加 = 总尝试 3 条）；
  达到上限后**换方法**（换模式/换参考/拆镜/改规划），不无限重生。
- "首次生成与追加重试分别记录"；网络或排队失败的技术重试与"已完成但画面
  不合格"的重生分开统计。
- 达到上限仍未达标：如实记录未达标，升级用户或换方法；不把最好的一条
  包装成方法成功。

## 报告口径

- 三档结论必选其一：原片整体合格 / 原片有错但可裁切得到合格片段 / 裁切仍
  不能完成剧情任务。
- 剪后可用也保留原片错误记录（错误时间区间不删）。
- 修复候选永远带候选身份；"修复完成"与"用户接受"是两个事件，不混写。
- 用户仍不满意时：报告当前方法未达画质目标，不用"相对改善"抵消"绝对
  未达标"；更换模型是下一步备选（如实说明）。
