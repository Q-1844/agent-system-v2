# Agnes 制作工艺候选包：首帧·动作因果·衔接·修复（agnes-production-craft v0.9.0）

## 身份与优先级（先读）

- 本包是 **Phase49 候选 Skill**（source=builtin，版本 0.9.0），用于对照试验；
  不是正式版替换。正式 Skill `full-story-relay-calibration` v1.4.0 / 
  `keyframes-bridge-repair` v1.4.0 原文保持冻结，不被本包修改。
- **优先级规则**：绑定本包的工作流节点，制作决策（首帧方法、动作规划、衔接
  方式、审片与裁切判断）以本包为准；keyframes 桥接的具体方法仍读关联技能
  `keyframes-bridge-repair`；canonical、权限、OCC、锁、回执、用户选版等治理
  规则全部保留，本包不授予任何新权限。
- 旧组（绑定 full-story-relay-calibration 的节点）不受本包影响；两组都接收
  相同的素材时长政策（见下）。

## 目的

把制作决策集中在真实出片质量上：先有合格的帧，再有清楚的动作因果，然后
完整审片——能裁切保留完整剧情区间就给剪辑建议，关键节点错误必须修根因，
绝不靠剪掉关键过程伪装合格。

## 素材时长政策（本轮生产红线）

| 镜头情况 | 请求时长 | 规划重点 |
| --- | --- | --- |
| 简单反应、观察、轻微动作 | 8 秒 | 起态清楚，动作后有可读结果 |
| 常规单主动作、普通叙事镜头 | 10 秒（默认） | 准备 → 执行 → 结果，保留剪辑余量 |
| 关键接触、道具交接、完整起止阶段 | 10–12 秒 | 接触与持有者变化完整可见，不同时复杂运镜 |

- 官方接口允许 4–12 秒；**至少 8 秒是本轮生产政策，不是接口下限**。
- 请求、任务回执、下载文件的真实时长都要核对；文件真实时长异常要记录，
  不只看请求里的 seconds。接口默认时长（5 秒）不得直接使用。
- 秒数是素材总长度，不是模型内部动作时间的精确承诺；提示词用动作阶段表达
  顺序，关键接触不安排成只能发生在最后瞬间。
- 复杂动作 12 秒内仍不清楚 → 拆镜；拆出的每条新素材仍 ≥8 秒。
- **生成素材时长与成片保留时长分开**：成片一镜可以短于 8 秒；本轮交付的是
  有剪辑余量的源素材。

## 每镜规划必须表达的内容（写入既有分镜字段，不新建 schema）

1. 剧情任务：观众必须理解的一个核心动作或变化。
2. 起始状态：人物数量、位置、姿态、道具持有者及接触关系。
3. 主动作步骤：因果顺序和必须可见的关键事件。
4. 必须保留的内容：关键接触、交接、身份亮相和结果状态。
5. 结束状态：为下一镜或剧情理解提供什么事实。
6. 生成素材时长：≥8 秒，并说明为何选该长度。
7. 剪辑余量：可删减的准备、停顿、结果停留；不能删掉的过程。
8. 衔接要求：动作延续 / 空间延续 / 身份保持 / 正常切镜。

剪辑余量不是必须静止的填充时间：准备动作、视线、环境运动和结果停留要自然。

## 总体工作流

```
[规划] 按上表逐镜定起态/动作/结果/时长/余量/衔接
   ↓
[首帧] 按 references/first-frame-image.md 生成并审首帧；
        首帧合格才进入依赖该首帧的视频生成
   ↓
[视频] 按 references/video-action-causality.md 规划提示词与模式，
        请求 ≥8 秒；提交后核对回执与文件真实时长
   ↓
[完整审片] 先完整播放，再按关键动作/接触点/疑似错误补查帧；
        首中尾抽样不能替代完整审片
   ↓
[裁切判断] 按 references/repair-diagnosis.md 的顺序：
        能保留完整剧情区间 → 交付具体剪辑建议（保留源素材）
        关键节点错误 → 修根因后重做，不以剪代修
   ↓
[接力] 有动作接力依赖时，先确定实际保留区间与离开状态
        （references/shot-continuity.md），再规划下一镜
   ↓
[装配] 交付源素材、建议区间与依赖说明；最终选用由用户决定
```

## 错误是否可剪（判定表）

| 观察 | 处置 |
| --- | --- |
| 瑕疵只在开头或结尾，主动作与结果完整连续可读 | 提出裁切区间，保留源素材；核对剪后叙事与声音 |
| 中间有瑕疵，但前部或后部已完整表达剧情任务 | 选完整合格区间；不因瑕疵在中间就一律重做 |
| 错误在必须保留的交接、接触、身份或因果节点 | 不允许删掉关键过程后宣称合格；修复或重新规划 |
| 主动作和结果分落在错误区间两侧，拼接会跳步 | 不作为单镜裁切成功；改多镜表达须单独验证 |
| 整段身份、人数、关键道具或动作因果错误 | 回根因层修复，延长素材不能挽救 |
| 画面可保，但裁切使关键音效脱离动作或留半句人声 | 音频复核；不能只以画面放行 |

## 完成标准

- 每镜有：规划字段（含时长与余量）、首帧证据、视频请求与回执、真实时长核对、
  完整审片记录（错误时间区间 + 必须保留事件）、裁切判断结论（可保留区间或
  修根因记录）。
- 每条新素材真实时长 ≥8 秒且与回执一致；异常已记录。
- 每个有错误的镜头明确归入三档之一：原片整体合格 / 原片有错但可裁切得到
  合格片段 / 裁切仍不能完成剧情任务。剪后可用也不抹掉原片错误记录。
- 修复候选保持候选身份；正式选版未被替换前，下游继续指向原选版。
- 接力镜记录：所依据的端点（源物理尾帧 / 最后保留帧）、版本、时间或帧号。
