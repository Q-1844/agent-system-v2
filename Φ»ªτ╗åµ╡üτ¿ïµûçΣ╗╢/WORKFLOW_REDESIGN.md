# 工作流重设计：五步流程（设计文档，未动代码）

> 状态：设计稿，待用户确认。确认后再动代码。
> 背景：当前"剧本/Characters/Storyboard"三入口、角色管理碎片化（剧本编辑器 + Characters 页 + 角色库三处都能管角色），新用户看不懂流程。本设计重做成清晰的五步线性流程。

---

## 一、目标

把当前三入口重做成**五步线性流程**，顶部步骤条引导，前置未完成则后续置灰 + 提示原因。解决"角色定义 vs 角色出图"职责重叠、标题中英混排、流程不可见三个核心问题。

## 二、五步总览

| 步骤 | 页面标题 | 一句话职责 | 现状映射 |
|---|---|---|---|
| 1 | 项目 | 建项目 + 定风格/画幅（一次定，全局生效） | Dashboard 的项目选择 + 新增风格画幅设定 |
| 2 | 剧本 | 写故事 + 定义角色（文字）+ 拆场景 | script-editor（已存在，强化为角色唯一定义入口） |
| 3 | 角色 | 给剧本里的角色出三视图并锁定 | Characters 页（删新增输入框，改只读 + 出图） |
| 4 | 分镜 | 场景拆镜头，每镜 首帧->配音->尾帧->视频 | ShotBoard（已存在，基本不动） |
| 5 | 导出 | 拼接 + 音轨 + 字幕 -> final.mp4 | MainLayout 顶栏导出按钮抽出成独立页 |

## 三、跨步通用

### 3.1 顶部步骤条（Stepper）
- 横向五步：项目 -> 剧本 -> 角色 -> 分镜 -> 导出。每步状态：`未开始 / 进行中 / 已完成 / 已跳过`。
- 当前步高亮。点击可跳转（满足进入条件时）；不满足则**置灰 + tooltip 提示原因**（复用阶段4"按钮禁用 + 黄色提示"模式，如 ShotCard 未选首帧时视频按钮禁用）。
- **进入条件基于数据前置，非严格线性**：分镜不硬依赖角色（角色无图时首帧走文生图，一致性降低但不报错）。步骤条把"角色"标"推荐完成"但不置灰"分镜"。详见各步进入条件。

### 3.2 风格角标
- 所有生图界面（步骤3 三视图、步骤4 首帧/尾帧）右上角显示当前风格徽标，如 `写实 · 16:9`。
- 数据源：步骤1 设定的 `project.style`。让用户随时知道会生成什么样。

### 3.3 标题统一中文
- 菜单 + 步骤条：**项目 / 剧本 / 角色 / 分镜 / 导出**。去掉 Dashboard / Characters / Storyboard 英文混排。
- 队列面板保留为顶部按钮（跨步通用，非步骤）。

### 3.4 角色库（savedCharacters）
- **不再作为并列数据源常驻角色页**。
- 改成显式"从库导入"按钮：点击弹库列表，选中即把该角色（名 + 描述，若库里有图也带图）加进**项目角色（写入步骤2 数据）**。导入后可在步骤3 出图/确认。
- 默认角色（小星/暗影）仍在库里，通过"从库导入"加进项目，不再自动出现在项目角色列表。

### 3.5 道具/物品
- **暂不做独立管理**。与角色共用同一套机制（角色页可放"物品"角色，描述当 prompt 出图）。
- 等跑完一部片子再决定是否独立成类。现在加 = 无使用经验下扩大复杂度。

## 四、各步详述

### 步骤 1：项目

**页面职责**
- 新建项目 或 选择已有项目。
- 设定三要素：项目名、风格（写实 / 2D动画 / 3D / 水墨 四选一）、画幅比例（16:9 / 9:16 / 1:1）。
- 风格 + 画幅在此定一次，后续所有生图（角色三视图、分镜首帧/尾帧、视频尺寸）自动带上。

**数据依赖**
- 读：项目列表（选已有）。
- 写：`Project.name`、`Project.style.art_style`（四风格映射到 prompt 后缀串）、`Project.style.aspect_ratio`、`Project.style.size_tier`（1K 固定）。
- 风格映射（`art_style` 串）：
  - 写实 -> `"realistic, photographic, highly detailed"`
  - 2D动画 -> `"anime, 2d animation, cel shading"`
  - 3D -> `"3d render, pixar style, octane render"`
  - 水墨 -> `"chinese ink painting, traditional ink wash, xuan paper"`

**进入条件**：无（入口步，始终可用）。

**完成标准**：项目名非空 + 风格已选 + 画幅已选 + 已保存（后端有此项目记录）。

---

### 步骤 2：剧本

**页面职责**
- 结构化编辑（不要求用户写裸 YAML）：项目信息（只读，来自步骤1）+ 角色列表 + 场景列表。
- **角色定义的唯一入口**：在这里加 / 编辑 / 删角色（名 + 文字描述）。Characters 页不再能加角色。
- 拆场景：每场含 描述、台词、镜头（景别/运镜）、光照、出场角色。
- 保存 -> 解析成 project.json（v2）。

**数据依赖**
- 读：`Project`（name/style/ratio 来自步骤1）。
- 写：`Project.characters`（name + description_en，**纯文字，无图**）、`Project.scenes`（description / dialogue / camera / lighting / characters）。

**进入条件**：步骤1 完成（项目有 name + style + ratio）。

**完成标准**：≥1 场景已定义并保存。角色数 ≥0（无角色的剧本允许，步骤3 自动跳过）。

---

### 步骤 3：角色

**页面职责**
- **只读列出步骤2 定义的角色**（名 + 描述），**不能再在此加角色**。
- 每个角色一个"生成三视图"按钮 -> 进三视图生成（保留现有 single / chain / sheet 三法）。
- 生成后挑选 / 锁定（selected），绑到项目（reference_images）。
- "加角色"入口 -> 跳回步骤2（提示"角色在剧本里加"）。
- "从库导入"按钮 -> 弹角色库，导入到项目（写入步骤2 角色）。

**数据依赖**
- 读：`Project.characters`（来自步骤2）。
- 写：`Project.characters[name].views`（front/side/back 的 local + url，即 reference_images）。
- 生图 prompt 用**步骤1 的风格**（不再硬编码 "anime"）+ 角色描述。三视图比例固定 2:3 竖图（角色全身），**不跟项目画幅**（画幅是给分镜/视频的）。

**进入条件**：步骤2 完成（有解析后的剧本）。若剧本里 0 个角色 -> 本步显示空状态"去剧本加角色"，**不阻塞**（标记"已跳过"，步骤4 可进）。

**完成标准**：所有"出场角色"（在任一场景 `characters` 列表里出现的角色）均已生成并锁定正面图（front view）。侧面 / 背面推荐但非必须。

---

### 步骤 4：分镜

**页面职责**
- 现有 ShotBoard：场景 -> 镜头，每镜 首帧 -> 配音 -> 尾帧 -> 视频。
- 首帧生成自动取步骤3 锁定的角色参考图（公网 url 或 base64）。
- 候选点选、link_mode、锁定、队列进度等现有功能保留。

**数据依赖**
- 读：`Project.scenes/shots`、`Project.characters.views`（步骤3，作首帧参考）。
- 写：`Shot.first_frame` / `audio` / `last_frame` / `video`。

**进入条件**：步骤2 完成（有场景）。**不硬依赖步骤3** -- 角色无参考图时首帧走文生图（一致性降低但不报错）。步骤条把步骤3 标"推荐完成"但不置灰步骤4。

**完成标准**：所有镜头 `video.status = done`。

---

### 步骤 5：导出

**页面职责**
- 一键合成：拼接所有 video-done 镜头 + 整条音轨 + 烧全片字幕 -> final.mp4。
- 预览 final.mp4 + 下载按钮。
- 显示成片信息（总时长、分辨率、镜头数）。

**数据依赖**
- 读：所有 video-done 镜头、audio、subtitle_srt。
- 写：`output/final.mp4`。

**进入条件**：≥1 个镜头 `video.status = done`。

**完成标准**：final.mp4 已生成（最新一次合成）。

## 五、数据模型影响

- `StyleAnchor.art_style`：从自由串改成枚举映射（四风格），旧值 `"anime, cinematic composition"` 兼容映射到"2D动画"。
- 角色生成（`_build_view_prompt` / `_build_img2img_prompt` / `_build_sheet_prompt`）：style 参数从 `req.style`（默认 "anime"）改读 `project.style.art_style`。
- Characters 页：删 `newCharName` / `newCharDesc` 输入框；角色列表改只读从 `Project.characters` 读。
- `savedCharacters`：从常驻列表改成"从库导入"弹窗。
- 新增组件：`Stepper`（步骤条）、`StyleBadge`（风格角标）。
- 新增页面：项目设定页（步骤1）、导出页（步骤5）。
- 菜单：Dashboard -> 项目（或 Dashboard 保留作队列总览，项目作步骤1）；Characters -> 角色；Storyboard -> 分镜；新增 导出。
