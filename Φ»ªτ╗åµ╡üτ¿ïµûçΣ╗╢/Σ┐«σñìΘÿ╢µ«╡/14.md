# Agnes Audio Capability Probe A0

## Native Audio / Dialogue / Voice Identity / Music Continuity / Audio Reference Investigation

当前 Visual V1 已完成 Golden Path。

本阶段：

> **只调查 Agnes 的真实音频能力。**

不要设计正式声音架构。

不要实现：

* VoiceProfile
* Dialogue canonical
* TTS pipeline
* lip-sync pipeline
* soundtrack system
* audio mixer
* Agent integration
* Shot schema changes
* Binding schema changes
* production UI

原则：

```text
measure first
design later
```

---

# 0. 调查目标

已知真实事实：

当前真实 Agnes Video 输出 MP4 含：

```text
AAC
48kHz
stereo
```

但用户过去实际观察：

```text
1. 环境音通常尚可
2. 自动配乐有时尚可
3. 人物说话声音质量差
4. 切换 Shot 后人物音色可能改变
5. 切换 Shot 后背景音乐可能改变
```

本阶段要验证这些问题的真实程度，并回答：

```text
Agnes 原生声音到底适合承担什么生产职责？
```

不要试图证明 Agnes “好”或“不好”。

按证据得结论。

---

# 1. 开工原则

优先建立独立 scratch：

```text
_audio_probe/
```

所有测试产物、request、metadata、ffprobe、评价表放这里。

默认：

```text
production code diff = 0
```

不要修改现有 Shot generation pipeline。

直接复用当前已经工作的 Agnes client/config 或使用独立 probe 调用。

不得：

* 修改生产 prompt builder
* 调整现有视觉 adapter
* 为测试结果写特殊 production path

---

# 2. 首先调查真实 provider capability

读取：

```text
src/api/agnes_client.py
```

以及当前 Agnes 官方 Video 文档。

分别确认：

```text
agnes-video-v2.0
agnes-video-2.5
agnes-video-2.5-flash
```

当前账户/代码实际可用哪些。

为每个模型建立表格：

| Capability                          | v2.0 | 2.5 | 2.5-flash |
| ----------------------------------- | ---: | --: | --------: |
| native audio output                 |      |     |           |
| dialogue from prompt                |      |     |           |
| music from prompt                   |      |     |           |
| ambience / SFX                      |      |     |           |
| audio reference input               |      |     |           |
| number of audio refs                |      |     |           |
| keyframe + audio ref simultaneously |      |     |           |
| image reference                     |      |     |           |
| first/last frame                    |      |     |           |
| seed                                |      |     |           |
| negative audio instruction          |      |     |           |

只写真实 API。

不要根据行业常识猜。

# 3. 所有输出必须保存音频证据

每个真实视频：

保存：

```text
video.mp4
audio.wav
ffprobe.json
request.json
provider_response.json
notes.json
```

使用 ffmpeg/ffprobe 提取：

```text
codec
sample rate
channels
bitrate
duration
loudness if practical
```

为方便人工 A/B，对每组测试额外生成：

```text
comparison montage / concatenated audio
```

例如：

```text
Alice_same_character_01.wav
Alice_same_character_02.wav
...
Alice_same_character_08.wav
```

再拼：

```text
Alice_voice_continuity_AB.wav
```

便于直接听出换嗓。

---

# 4. Test A — Native Audio Baseline

使用同一张视觉起始图、同一 prompt。

生成至少：

```text
N = 5
```

独立样本。

内容：

```text
一个安静的室内场景。
角色不讲话。
只发生轻微自然动作。
```

Prompt 不主动要求：

* music
* speech
* sound effect

记录模型自行生成：

```text
speech?
music?
ambience?
SFX?
silence?
```

目标：

> Agnes 在用户完全不指定声音时，会主动生成什么？

---

# 5. Test B — Environment / Foley

建立三个简单事件。

例如：

### B1

```text
人物在木地板上走路
```

目标声：

```text
footsteps + room tone
```

### B2

```text
人物放下一把金属手枪
```

目标声：

```text
metal contact
```

### B3

```text
海边强风
```

目标声：

```text
wind + waves
```

每组至少生成 3 次。

评价：

```text
event synchronization
appropriateness
timing
artifact level
```

重点判断：

> Agnes 是否特别适合承担 visual-aware SFX / ambience。

---

# 6. Test C — No-Music Compliance

这是非常重要的生产测试。

明确 prompt：

```text
No music.
No score.
No soundtrack.
Only natural room ambience and synchronized action sound.
```

同一场景生成至少 5 次。

记录：

```text
是否仍出现 BGM
是否出现 tonal music
是否完全服从 no-music 指令
```

然后反向测试：

```text
Music only.
No dialogue.
Minimal environmental sound.
```

判断声音层是否可被可靠分离控制。

---

# 7. Test D — 中文精确对白

固定同一角色视觉。

测试极短中文：

```text
Alice 说：
“我们现在出发。”
```

至少：

```text
5 generations
```

再测试稍长：

```text
“灯塔马上就要停电了，我们必须赶在暴风雨之前进去。”
```

至少：

```text
5 generations
```

必须记录：

* 是否真的有语音
* 是否中文
* 实际听到什么
* 漏字
* 多字
* 改写
* gibberish
* 性别/年龄感是否符合角色
* clarity
* prosody

如果项目已有可用 STT：

转写后计算：

```text
CER
```

如果没有：

不要引入大型生产依赖。

做人工逐字 transcript 即可。

---

# 8. Test E — 英文精确对白

使用相同测试结构。

例如：

```text
“We leave now.”
```

以及：

```text
“The lighthouse is losing power. We have to get inside before the storm arrives.”
```

目的：

判断问题来自：

```text
Agnes speech generation generally
```

还是：

```text
Chinese-specific weakness
```

---

# 9. Test F — Same Character Voice Identity

这是本轮最高优先级之一。

固定：

```text
same Alice visual identity
same age
same appearance
same scene family
```

制作 8 个不同 Shot。

每个 Shot 都让 Alice 说一句短对白。

例如：

```text
Shot 1: 我们走。
Shot 2: 等一下。
Shot 3: 门锁住了。
Shot 4: 把灯打开。
Shot 5: 你听见了吗？
Shot 6: 风越来越大。
Shot 7: 快进去。
Shot 8: 别回头。
```

不要在 prompt 中人为描述八种不同声音。

输出拼接：

```text
alice_voice_identity_8shots.wav
```

人工 blind review：

```text
1 = 明显是不同人
2
3 = 有漂移但像同一个 voice family
4
5 = 稳定像同一个人
```

至少两轮独立听评。

记录：

```text
voice_identity_consistency
gender consistency
age consistency
accent consistency
pitch drift
timbre drift
prosody drift
```

---

# 10. Test G — Same BGM Across Shots

使用同一个连续 Scene。

生成：

```text
Shot 1
Shot 2
Shot 3
Shot 4
Shot 5
```

prompt 中都要求：

```text
同一低沉悬疑弦乐配乐持续
```

不要给外部 music reference。

拼接五个 audio。

评价：

```text
是否像同一首曲子
key consistency
tempo continuity
instrumentation continuity
motif continuity
cut discontinuity
```

核心问题：

> prompt 文字是否足以维持跨 Shot music identity？

预计不要假设能。

---

# 11. Test H — “Continue Previous Music”

如果 Agnes 接口没有明确 cross-shot audio state：

仍可以测试自然语言：

```text
Continue exactly the same background score from the previous shot.
```

给视觉 continuity，但不提供音频 reference。

观察：

```text
是否真的能延续
```

如果失败：

明确结论：

```text
textual continuity instruction is not audio identity
```

---

# 12. Test I — Same Character + Different Shot

这是把 F 做得更接近实际动画。

Alice 连续经过：

```text
wide
medium
close-up
different camera angle
different action
```

但角色与声线应不变。

测：

> 视觉构图改变是否导致 Agnes 重新采样 speaker identity。

---

# 13. Test J — Two Speakers

Alice + Bob。

指定：

```text
Alice: “门开了吗？”
Bob: “还没有。”
Alice: “那就快一点。”
```

至少生成 5 次。

评价：

```text
speaker separation
line assignment
voice differentiation
speaker swap
line omission
line rewriting
```

判断 Agnes 是否具备真正可生产的：

```text
multi-character dialogue
```

---

# 14. Test K — Lip Sync

选 D/E/J 中实际语音较清晰的样本。

人工评价：

```text
mouth moves at correct speech period
start synchronization
end synchronization
syllable-level plausibility
mouth continues after voice
voice continues after mouth
```

不要把：

```text
人物嘴在动
```

等价成：

```text
accurate lip sync
```

---

# 15. Test L — Audio Reference Capability

仅当真实 API 支持时执行。

不要改生产代码。

准备一个干净、单 speaker 的固定参考音频。

要求：

```text
same reference audio
same character
different visual shots
```

至少 5 次。

测试问题不是只有：

```text
有没有声音
```

而是：

```text
reference 是否控制：
speaker timbre?
prosody?
rhythm only?
content?
emotion?
```

必须区分。

---

# 16. Test M — External Voice as Reference

如果 Agnes 支持 audio reference：

使用一个质量明显高于 Agnes native speech 的固定外部语音样本。

来源可以是：

```text
项目当前已有合法 TTS
或
测试用非敏感、可授权 speech sample
```

不要为了 probe 接入新的 production provider。

测试：

```text
外部 voice
→ Agnes audio reference
→ character video
```

判断：

```text
voice identity retention
speech content retention
lip synchronization
visual degradation
```

如果模型重新说了一遍、改变音色、改变文字：

明确记录。

---

# 17. Test N — Music Reference

如果 audio reference 可以接受音乐：

输入固定 8–10 秒测试音乐。

连续制作多个视觉 Shot。

判断：

```text
music preserved?
recomposed?
tempo only preserved?
motif preserved?
pitch changed?
```

这关系到：

> Agnes 是否能通过 master music reference 维持跨镜配乐。

---

# 18. Test O — Voice Reference + Visual Consistency Trade-off

尤其调查 2.5。

如果：

```text
keyframe mode
```

和：

```text
audio/reference mode
```

不能同时使用，则做直接对照。

### O1

```text
keyframe
→ best visual consistency
→ native audio
```

### O2

```text
reference/audio
→ external voice control
→ reference visual control
```

比较：

```text
face consistency
costume consistency
scene consistency
motion
voice
lip sync
```

这是声音架构设计最重要的证据之一。

---

# 19. Test P — Can We Disable Native Layers?

分别要求：

```text
dialogue only
no music
minimal ambience
```

```text
ambience only
no dialogue
no music
```

```text
music only
no dialogue
```

```text
silent
```

至少 3 次/组。

如果模型不能稳定遵守：

必须得出：

> native Agnes output is a mixed generative soundtrack, not a controllable audio stem system.

---

# 20. Output Stem Investigation

检查 MP4。

确认到底只有：

```text
one stereo AAC stream
```

还是存在：

```text
speech track
music track
SFX track
```

如果只有一个混合轨：

明确记录：

```text
no stems observed
```

不要因为听得出三个元素就称其为独立 tracks。

# 22. 最终报告

生成：

```text
AGNES_AUDIO_CAPABILITY_PROBE_A0_REPORT.md
```

必须回答：

## A. Native Sound

Agnes 自动生成：

* ambience
* SFX
* music
* speech

分别表现如何。

## B. Dialogue

指定台词：

```text
accuracy
clarity
language
```

## C. Voice Identity

同角色跨 Shot：

```text
stable or drifting?
```

## D. Music Identity

跨 Shot：

```text
stable or regenerated?
```

## E. Lip Sync

实际能力。

## F. Audio Reference

它究竟控制什么。

## G. Layer Control

能否禁止 music/dialogue 等。

## H. Output Editability

是否只有 mixed stereo audio。

## I. Visual Trade-off

audio/reference mode 是否牺牲当前 keyframe visual control。

## J. Recommended Production Role

只能根据实测，从以下选：

```text
1. Agnes native audio can serve as final soundtrack
2. Agnes suitable for ambience/SFX, not precision dialogue/music
3. Agnes suitable as audiovisual performance engine driven by external voice
4. Agnes audio should be discarded/muted for production
5. hybrid
```

可以多选并给适用条件。
