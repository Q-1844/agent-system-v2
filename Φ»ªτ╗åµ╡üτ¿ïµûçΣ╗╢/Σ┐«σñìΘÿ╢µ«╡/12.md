# 1. 第一项必须完成的审计：Boundary-frame provenance

这是本阶段新增的最高优先级问题。

S3C.1 中：

```text
BoundImageRequest.basis
```

是 ephemeral generation request provenance。

请确认：

> 当前生成出的 first-frame / last-frame artifact 是否保存了足够的信息，能够证明它是基于当前 Binding / Pack basis 生成的。

重点调查：

```text
first frame artifact
    ↓
是否记录：
binding revision?
binding document revision?
resolved dependency fingerprints?
resolved SIV?
visual profile fingerprint?
reference IDs?
generation input basis?
```

不要默认：

```text
Binding READY
=
现有 first-frame 一定 fresh
```

这两个命题不等价。

例如：

```text
T1:
Binding revision 3
→ generate first frame A

T2:
Alice Look changed
→ binding stale

T3:
explicit refresh
→ Binding revision 4 / READY

但 first frame A 仍然在磁盘
```

此时如果 video generation 直接使用：

```text
first frame A
```

则不能仅因为当前 Binding READY 就把它当成 current production evidence。

## 必须判断当前代码属于哪一种

### Case A — 已有可信 provenance

如果现有 image/video result metadata 已经能够证明：

```text
artifact basis == current generation basis
```

复用它。

不要建立第二套。

### Case B — 当前视频生成在同一次 operation 中重新生成 boundary frame

如果 first/last frame 与 video 属于一个受保护的完整 generation operation，并可以证明 basis 一致，则说明真实机制并测试。

### Case C — 已存 artifact 无 basis/provenance

不要静默假定 fresh。

此时先判断最小正确修复是什么。

允许考虑：

```text
generation-result metadata
```

记录最小的 derived provenance/basis。

但它必须满足：

* 不是新的 production canonical
* 不成为 Binding 的替代品
* 不改变 Shot creative truth
* 不反写 Resources / Scene / Profile
* 只描述“这个生成结果是基于什么产生的”
* deterministic / inspectable
* 不自动 refresh

如果需要修改现有 generation-result metadata schema：

必须在报告单独列为 deviation，并解释：

1. 为什么 video correctness 离不开它
2. 为什么它只是 artifact provenance，不是第二套 canonical
3. backward compatibility
4. legacy artifact 无 provenance 时的行为

如果无法在本阶段边界内安全解决：

> STOP 该路径并报告，不得假装 existing frame fresh。

# 6. Last-frame temporal rule

S3C.1 已锁定 first-frame：

```text
start        INCLUDE
throughout   INCLUDE
static       INCLUDE
end          EXCLUDE
```

S3C.2 必须锁定 last-frame：

```text
start        EXCLUDE
throughout   INCLUDE
static       INCLUDE
end          INCLUDE
```

注意：

> temporal eligibility 必须先于 priority。

所以：

```text
priority=primary
temporal_scope=start
```

在 last-frame 中仍必须排除。

同理：

```text
priority=primary
temporal_scope=end
```

在 first-frame 中仍必须排除。

不要因为 primary 覆盖 temporal。

# 7. First-frame 与 Last-frame 不能共享同一个“current state”

例如：

```text
Alice picks up Pistol
```

Binding：

```text
start_state = right hand empty
end_state   = right hand holding pistol
```

正确：

```text
FIRST
Alice Look / empty-hand state
Pistol identity
Scene
NO already-holding Composition as current evidence

LAST
Alice holding-Pistol Composition
Scene
end state
```

错误：

```text
first refs + end refs
全部混入同一个 generic image_refs
```

然后让 provider 自己猜哪个是开始哪个是结束。
