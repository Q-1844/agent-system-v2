# 7. Dialogue parser production hardening

B1 parser 已经成立。

本阶段保留：

```text
换行切句
speaker prefix
single_auto
explicit binding
multi-character fail closed
speaker ∈ Shot.characters
```

但必须补一个真实 production 风险：

## Stage Directions

当前 B1 会保留：

```text
（低声）
（转身）
（停顿）
```

等内容。

本阶段必须明确区分：

```text
spoken content
```

与：

```text
non-spoken direction
```

最小规则：

### 全行 parenthetical

例如：

```text
（林晚星转身看向门口）
```

或者：

```text
(Gu Yan pauses)
```

明确作为：

```text
non_spoken_direction
```

绝不放进 spoken dialogue。

### Speaker + stage direction + dialogue

例如：

```text
林晚星：（低声）别过去。
```

不得把：

```text
低声
```

当台词朗读。

如果能够以确定性规则安全切分：

```text
delivery/performance hint = 低声
spoken text = 别过去。
```

可以派生。

如果格式无法唯一解析：

```text
ambiguous_dialogue_markup
```

fail closed 或 warning + 不生成。

**不得用 LLM 临时解释字符串。**

# 11. Prompt Compiler V1 的四个语义区

最终 prompt 至少表达四类不同事实：

```text
1. Visual / performance intent
2. Non-spoken action
3. Spoken dialogue
4. Native sound environment
```

它们可以继续序列化为 Agnes 已验证的单行文本。

**不要求多行格式。**

重要的是语义隔离。

---

# 12. 第一条 Prompt 红线：只有 Dialogue 可以被说出来

B1 已经发现当前 uncontrolled A 侧会：

> 把 motion prompt「它微微点头，转身欲行」当台词念出来。

因此 prompt 中必须有明确约束：

```text
Only the explicitly quoted dialogue is spoken aloud.
Do not speak, narrate, or read any visual description,
camera instruction, action description, character motion,
sound-effect instruction, or production note.
```

语义可以优化。

但要求必须明确存在。

这条应该成为：

```text
Native AV Prompt Compiler invariant
```

不是某一个 sample 的临时 patch。

---

# 13. 第二条 Prompt 红线：台词不得改写

Dialogue text：

```text
不得翻译
不得润色
不得总结
不得自行补句
不得生成新的对白
```

Compiler 应明确告诉 Agnes：

```text
Speak exactly the supplied dialogue.
Do not invent additional spoken lines.
```

但：

```text
自然语气
呼吸
非语言 vocalization
```

可以由表演自然产生，只要不改变台词含义。

不要走到机械 TTS。

---

# 14. Speaker assignment prompt

多人 Shot：

Prompt 必须确定性表达：

```text
Line 1 → Character A
Line 2 → Character B
Line 3 → Character A
```

并明确：

```text
Do not swap speakers.
```

对 silent character：

```text
Character B remains silent in this shot.
```

B1 已经证明这一类控制有效。

正式保留。

# 15. 音画创作原则：让声音跟动作共同发生

Native AV 最大优势不是：

> “视频顺便带音轨。”

而是：

> **动作和声音由同一次生成共同解释。**

Prompt Compiler 应利用已经存在的：

```text
opening_state
end_state
motion
action_sequence
environment_motion
production context
```

让 dialogue 和动作关系清楚。

例如：

```text
顾岩走到门边
→ 推门
→ 门轴响
→ 顾岩停下
→ 说台词
```

不要简单变成：

```text
动作描述一大段
+
台词孤立放最后
```

如果 existing action_sequence 已经表达顺序：

> 保留顺序并编译成自然的 performance timing。

但不要自动发明不存在的动作。

# 17. Music policy

B1 人评仍然发现一些镜头出现不必要背景音乐。

因此正式定义：

## Dialogue Shot 默认

```text
music_policy = "none"
```

prompt 语义：

```text
No background music or musical score.
Use only natural dialogue, diegetic sounds,
and appropriate environmental ambience.
```

目标：

> 去掉随机 BGM，但保留门声、脚步、环境声。

## 明确需要原生音乐的特殊 Shot

允许：

```text
music_policy = "allow_native"
```

但这不是默认。

注意：

这不是正式电影配乐系统。

正式 Score 仍属于未来：

```text
Sequence Audio Post
```

# 18. Audio directives 必须是“意图”，不是手工时间线

允许：

```text
door creaks as it opens
footsteps stop before the line
soft rain outside
```

不要要求用户写：

```text

00:02.913 door.wav
```

Native AV 的价值就是让模型共同解释动作和声音。

如果需要精确 frame-level audio timeline：

那是未来另一个问题。

本阶段不要构建。

# 19. Director 开始具备 Native AV planning discipline

现在方向已经正式成立，因此允许修改：

```text
Director system prompt
```

但只修改创作规范。

不要改 Director Runtime / tools / Sub-Agent architecture。

加入以下原则：

### Dialogue

多角色对白：

```text
每句明确 speaker prefix
```

### Stage directions

不要把：

```text
动作
语气说明
镜头说明
音效说明
```

塞进 `Shot.dialogue`。

`Shot.dialogue` 只负责：

> 真正会从角色嘴里说出来的文本。

### AV staging

如果一句对白依赖明显动作：

Director 应让：

```text

```

与 dialogue 合理匹配。

例如：

```text
开门 → 停顿 → 说话
```

而不是同时塞入过多互相冲突的动作。

### Multi-speaker shots

不要因为技术原因全面禁止。

但创作上遵守：

> 没有明确价值时，不要在极短 Shot 里塞多个角色大量轮流说话。

这是电影语言和生成稳定性共同决定的。

### Shot-local sound

只有叙事上重要的声音才写 `audio_event_intent`。

不要给每个镜头填满琐碎 SFX。

# 25. Native AV freshness

建立 derived：

```text
NativeAVFreshness
```

至少：

```text
CURRENT
STALE
UNTRACKED_LEGACY
MISSING
```

### CURRENT

stored generation basis 与当前重算 basis 一致。

### STALE

例如：

```text
dialogue changed
speaker binding changed
spoken language changed
audio intent changed
music policy changed
visual basis changed
provider/model/options changed
prompt compiler schema changed
```

### UNTRACKED_LEGACY

旧 VideoVersion：

```text
generation_basis={}
```

不要粗暴判：

```text
STALE
```

旧视频仍然可以继续播放 / 保留 / 手工选择。

但系统应诚实表示：

> 无法证明其 Native AV freshness。

### MISSING

没有 selected/final video。

> “音频模块还缺什么？”

```text

```

```text
how the performance looks
how the performance sounds
how lips move
how actions and sounds synchronize
```

最后：

```text
VideoVersion
```

仍然是那个完整 Shot。
