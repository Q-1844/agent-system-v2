# AGNES_AUDIO_DIRECTION_CORRECTION_REPORT

音频架构方向修正报告（简单说明版）
日期：2026-09-15
依据：用户对 A0 探针素材的人工评审（2026-09-14 提交，评审网站 `_agnes_audio_review_server.py`，15 条反馈落盘 `_audio_probe/results/AGNES_AUDIO_REVIEW_FEEDBACK.json`）

## 1. 决策摘要

> **主路径改向：Agnes 原生音频生成（台词/声线/SFX/环境/音乐由视频模型一体生成）。**
> MiniMax 音频转岗为旁白（narration）专用；若 Agnes 后续也能稳定做旁白，则 MiniMax 旁白备用搁置。
> A2 外挂 lip-sync（Sync Labs）搁置不删，作为 fallback primitive 留档。

用户原话要点：效果出奇的好；之前判断失误；Agnes 原生配音流畅，控制其音频生成效果会很好；由 Agnes 生成音频一切更简单；Seedance 完全支持这种音视频一体模式，利于后续拓展。

## 3. 之前为什么误判

1. **A0 机测指标与人耳脱节**：A0 报告以 F0 散布（127Hz+）、LTAS 相似度等机测指标给出「跨镜声线不稳」的谨慎结论；人耳实测绝大多数镜头音色一致，真实瑕疵只是个别音色偏细 + 偶发 swap——远好于机测暗示。
2. **流程缺陷（主因）**：A0 报告交付时「人工听评尚未进行」，25 组听评包备好后一直无人验收，后续 A1/A2 都建立在「机测谨慎结论」之上。**本报告确认：这是「该听没听」造成的方向偏航，不是探测数据有错。**
3. 幸好偏航不远：A1/A2 全部资产保留可用（见 §4），无生产性沉没成本。

## 5. 新方向的技术图景（供 A3 规格参考，本轮不实现）

```
角色声线参考（A1 DialogueAudioVersion，per-character approved）
        ↓ 作为 audio reference 输入
Agnes 视频生成（台词进 prompt → 原生口型+配音+SFX+ambience 一体产出）
        ↓
音画天然同步（无需外挂 lip-sync / sync_input / mux）
```

- 一切更简单：省掉外挂 provider、上传、轮询、音频替换整条链；音画同步由模型原生保证（评审 ⑨「口型同步好」实证）
- **Seedance 完全支持音视频一体生成模式** → 该路线天然多 provider 可拓展（A2 沉淀的 provider-neutral pack/basis 思想可平移）
- 待解问题（进 A3 规格）：④偶发 swap 的防护（台词-说话人绑定校验）、个别音色偏细的重生成策略、旁白/对白/音乐的层级与混音（原 A3 议题收窄）

## 6. 经验教训

1. **机测结论 ≠ 人的耳朵**：涉及「听起来像不像/好不好」的判定，机测只能筛风险，不能下架构结论。
2. **听评包备好 ≠ 验收完成**：A0→A1→A2 的偏航根因是「该听没听」。评审网站模式自此为每阶段标配。
3. 幸运的是 A1/A2 均为「可转岗资产」——偏航成本 ≈ 0，且 A1 立即获得新角色（参考音源）。

## 7. 下一步

- 本轮不实现任何新代码；A1/A2/Visual 全部保持冻结现状。
