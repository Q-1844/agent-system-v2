# 5. 判断 transition 是否缺少中间动作

```text

2. 握住枪柄
3. 将枪抬离原位置
4. 转动手腕 / 枪身
5. 达到尾帧握持方向
```

然后与当前：

```text
action_sequence
BindingAction
prompt
```

比较。

回答：

> 哪些必要 transition 根本没有被表达？

# 12. Decision

## A 最好

如果 Boundary Correction 明显解决：

结论：

```text
PRIMARY CAUSE =
boundary-frame transition inconsistency
```

形成系统生产规则：

> First/Last Frame 不仅要各自正确，还必须具备合理的 temporal transition。

无需继续改 prompt。

---

## B 最好

如果 explicit action transition 明显解决：

结论：

```text
PRIMARY CAUSE =
under-specified transition
```

形成 Director / future Skill rule：

> 当 endpoint 存在显著 ownership / orientation / pose change 时，必须在 action_sequence 中描述必要中间动作。

---

## C 最好

如果 first-frame-only 明显优于 first+last：

结论：

```text
PRIMARY CAUSE =
provider first-last interpolation boundary
```

形成 production policy：

> 高 transition-load Shot 不应强制 first+last mode。

未来可考虑：

```text
first-frame only
split shot
intermediate keyframe
alternate provider
```

但本阶段不实现新的 routing system。

---

## D 揭示风格差异

如果写实显著稳定、动画持续失败：

记录：

```text
stylized rigid-prop interaction risk
```

进入未来 Director / Skills production knowledge。

不要修改 canonical。

---

## 所有方案仍不稳定

记录：

```text
Agnes prop-interaction provider capability boundary
```

接受：

```text
variant regeneration + selection
```

作为当前生产策略。

不要无限继续 prompt tuning。

---

# 13. 最重要的新 Production Principle

如果实验证实，应正式记录：

> **Boundary frames are temporal states, not merely good-looking images.**

即：

> 首帧和尾帧必须共同描述一个在当前 Shot 时长内可以合理发生的运动过程。

未来 boundary frame production 必须考虑：

```text
character pose
prop ownership
prop orientation
spatial relationship
action count
shot duration
```
