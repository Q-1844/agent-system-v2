========================
一、当前核心架构原则
========================

请严格遵守：

Resources 负责：
- Character
- Clothing
- CharacterLook
- Prop
- CharacterReferenceComposition
- ReferenceAsset

其中：

Character = 人物身份/Canonical Character

Clothing = 独立可复用服装资源

CharacterLook = Character + Clothing 的完整、经过审核的视觉组合

Prop = 独立可复用物品资源

CharacterReferenceComposition =
Character + approved CharacterLook + 1~3 Props + visual relations

例如：

Alice
+ Black Coat Look
+ Wooden Sword
+ Brass Compass
+ sword = right_hand
+ compass = left_hand

这是合法的 Resource-level visual composition。

但是：

“第 12 镜 Alice 原本没有剑，动作中拿起剑”

不应该写进 Resource Canonical。

这是 Shot / Video / temporal continuity 层面的信息。


Scene System 负责：

Location
LocationView
SceneInstance
SceneState
SceneInstanceView

其中：

Location = 稳定空间身份

LocationView = 该空间的稳定语义视角/视图锚点

SceneInstance = 某个 Story Scene 在某个 Location 上的实际场景实例

SceneState = 该 SceneInstance 当前的时间、天气、灯光、损坏、布置等状态

SceneInstanceView = 某个 SceneInstance + 某个 LocationView + 当前 SceneState 的视觉参考


ProjectVisualProfile 负责：

- photorealistic
- 2d_animation
- 3d_animation
- stylized
- custom
- art_direction
- style_tags
- negative_style_constraints

它是项目视觉风格的 Canonical。


Story Scene 保持轻量。

不要把资源 ID、图片 ID、复杂视觉生产状态塞进 Story Scene。

Shot 是生产汇合点。

========================
四、重点设计 Character Binding
========================

请特别考虑以下情况。

Case A：

Alice 穿黑色大衣。

应表达：

Character = Alice
Look = Alice + Black Coat

而不是：

Character = Alice
Image = alice_black_coat.png


Case B：

Alice 穿黑色大衣并且右手拿木剑。

应表达：

Character = Alice
Look = Black Coat Look
Prop = Wooden Sword
Relation = right_hand

系统可以复用：

CharacterReferenceComposition

但 Shot 不应该复制一份 Composition 的视觉真相。

Shot 应该引用语义资源，并由系统解析出所需 Reference Pack。


Case C：

Alice 换衣服。

例如：

上一镜：
Alice + Casual Clothing

这一镜：
Alice + Black Coat

这应该通过：

Look binding changed

表达。

不要修改 Character。

不要生成新的 Character。

不要把服装直接写进 Character。


Case D：

Alice 拿起手枪。

这一案例必须认真设计。

如果 Shot 是最终“已经拿着手枪”的静态画面：

Character = Alice
Look = Current Look
Prop = Pistol
Relation = right_hand

如果 Shot 是一个动作镜头：

Action = pick_up
Start State:
    right_hand = empty

End State:
    right_hand = Pistol

那么：

“拿起”不是 Resource。

“Pistol”是 Resource。

“Alice 当前是否拿着 Pistol”是 Shot / temporal state。

请检查当前 Shot / Video 系统是否已经有可以承载这种信息的结构。

如果没有，不要直接实现复杂 Timeline。

请先设计最小 V1 模型。

========================
九、Binding Validity Gate
========================

必须设计 Shot 是否可以进入生成阶段。

例如：

=> Shot NOT READY

SceneInstanceView stale
=> Shot NOT READY

Prop missing
=> Shot NOT READY

ProjectVisualProfile changed
=> Shot stale / NOT READY

但：

一个完全没有被当前 Shot 使用的 Clothing 改变

不能导致 Shot stale。

一个没有被当前 Shot 使用的 LocationView 改变

也不能导致 Shot stale。

必须是：

actual dependency

而不是：

整个 project 的任何资源变化。
