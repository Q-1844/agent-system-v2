## §1 两种协作模式（集成对象——纪律一字不减）

### 模式一：尾帧接力 + 自适应校准（relay-calibration loop）

**逐镜标准链路**（每镜必须走全，跳步=违规）：

```
预编剧冻结（每镜 description/motion/expected_tail/duration 齐备，生成开始前不改一字）
→ 字段落库 update_shot_fields（唯一正式 mutation 路径，自动 invalidate 旧 prompt；
   ⚠️ 新建 Shot 默认 link_mode=i2v，多参考直生/接力镜必须显式 link_mode=multi）
→ prompt 重建 POST /shot/{id}/prompt/rebuild {stages:["video"]}
→ binding refresh（GET binding_revision → POST refresh，OCC）
→ 提交生成（multi 模式：首镜=链根参考直生 video_reference_asset_id=<链根>；
   其余=prev_tail——按播放序解析上一镜尾帧，跨段自动成立）
→ 等末帧就绪（自动提取 + Pages 托管）
→ 接缝 MAE：上镜尾帧 vs 本镜首帧（128 灰度同刻度）——这是真正的接续性指标
   （提交时的 end-to-end MAE 量的是构图漂移，不是接缝；两者都记，语义分开）
→ Vision 结构化评估（仅证据，非裁定）
→ 执行者必须亲眼看图（Read 末帧图像）——Vision 已知盲区见下
→ 三档裁定 none/minor/major + 处置协议（见下）
→ trace 双落档：本地 JSON + REST run links（PUT /calibration/runs/{run}/links/{key}）
   含 repair 决策链全文（_repair_plan：根因→选项→选择→为什么）——这是 37C replay 语料
```

**三档裁定协议**（两轮实证：minor 吸收 12/12、retry 修复 5/5）：

| 裁定 | 判据 | 处置 |
|---|---|---|
| none | 尾帧与 expected_tail 高匹配 | 按预编剧继续 |
| minor | 叙事/情绪命中，机位/端点/朝向偏离 | 按预编剧继续——**下一镜预编剧首句吸收**（两轮 12/12 零文字修改）；不烧重试 |
| major | 叙事/情绪与剧本相反；地理丢失；主体不可见/被遮挡 | **单次重试**（retry 修复累计 5/5：N6a1、N9a1、M1a1、M3a1、M5a1） |

**major 重试的杠杆**（重试≠裸重掷）：
- 锚定文本：description **首句远景锚定 + 收束句「全身端立/尾态描述」**——破解特写吸引子连击
  （M4 三连击：a2 ECU→a3 MCU→a4 破解实证；camera_angle/composition 锚定不够，description 收束句才是关键）
- 日光/环境锚定（37A N4-r2 先例）
- **每次重试后必须重查负面约束**（M5a4 事故：空村出现一群儿童，Vision unexpected_elements 完全漏检）

**不重试的判据**（同等重要）：
- 机位偏但叙事命中 → accept+adapt（机位控制权在新镜 prompt+binding，relay 不锁机位）
- 动作端点未落尾帧（还差最后一下）→ accept+adapt（下一镜吸收）
- 强先验吸引子单独出现（smirk/play-bow 表情，狐狸+物体交互强先验）→ retry 无效（N9 道具同理），accept+adapt

**Vision 可靠性边界**（必须写进 agent 提示词）：
- 情绪/地理类偏离会误报 none（37A N6a1：描述了不存在的画面）
- 主体被遮挡 50%+ 时漏检（M1a1）
- unexpected_elements 会漏检人物闯入（M5a4 children）
- 结论：**Vision 只是证据，裁定者必须亲眼看图**；两者分歧时以看图为准并记录 vision_vs_human_diff

**接缝基线（三档告警阈值，38 实测）**：
- 同场景正常接力 ≈2（全链实测 1.7-2.4）
- 跨场景/构图切换 26-60（跨 Location 桥 26.0；环境切换本身不是主导因子）
- 剧变构图（暮色大远景）90+
- 超档 → 查接缝、按模式二处置

**级联纪律**：重生成链中任一镜 → 必查其下游接缝（下一镜首帧 vs 新尾帧）；
必要时顺延重生成（配额允许）或按模式二补桥。执行者必须在重生成时主动声明级联风险。

**人工裁定节奏（用户授权模式）**：Vision+执行者双读判 none/minor → 自动继续（页面补裁定标记）；
任何 major 或实质偏离 → 停下等用户裁定；用户在对话里给裁定。

### 模式二：keyframes 接续桥（bridge）

**定位（系统级认知，必须写进 agent 提示词）**：
系统三种视频生成模式的边界控制力**根本不同**——
- multi relay：只钉开场（上一镜尾帧），**尾帧自由落点** → 重生成上游必然造成下游接缝漂移
- i2v：只钉首帧
- **keyframes 桥：双端钉死（首槽+尾槽都是确定边界帧），中间过程=provider 插值**
→ **桥是接缝修复的标准手段（由构造保证双侧闭合），不是与 retry/accept 并列的选项**；
   retry 是重掷骰子（有方差事故风险），accept 是容忍断缝——都不是接缝修复。

**触发判据**：
- 尾帧与下一镜首帧状态差异大（跨 Location、大姿态反转）——38.md §2.3 原判据
- 重生成级联造成的下游断缝
- 任何需要「两端都对齐」的过渡

**构造七步**（38.md §2.3，全部走正式路径）：
```
1. 提取后继镜实际首帧：ffmpeg -i <后继.mp4> -frames:v 1
2. 上传 Pages 图床（build_image_host → GithubPagesHost，.env GITHUB_TOKEN）
3. insert_shots_after 插入桥梁镜（结构服务；桥 id 按段内计数器顺延，位次插在上镜之后）
4. binding 创建 + refresh → update_shot_relay(桥, 上镜) +
   REST PUT /shot/{桥} {opening_source: "inherit_previous", link_mode: "keyframes",
   transition_description: <过渡文本>, video_prompt_en: ""}
5. compile_reference_pack(桥).pack.basis → last_frame_batches 增批
   （candidates=[后继首帧 URL], generation_basis=basis）+ selected_last_frame 指针
   + last_frame.mark_done(local, url)
6. 提交生成（keyframes：首槽=上镜尾帧、尾槽=后继首帧，provider 插值）
7. 验收：双侧接缝 MAE（上镜尾→桥首、桥尾→后继首）+ 逐段帧检无跳转
```

**⚠️ basis 时序坑（违反=boundary_frame_stale）**：refresh → compile+seed → 提交；
**seed 之后零 refresh**（seed 的 basis 里含 binding_revision，再 refresh 会被顶掉）。

**时长纪律（用户指令，38 实测教训）**：**桥时长固定 10s 起步，不按静态配方缩短**——
时长过短=插值没有 morph 空间，两钉点之间直接切变（M5B a1 5s 中间跳转被用户拒）。
**transition_description 必须给中间节拍**（加情节铺路径：低头→嗅沿瓜皮→绕半步→鼻贴……），
两点一线的描述会诱发切变（M5B a2 10s+节拍定版实证）。

**验收**：双侧接缝 MAE 近零（1.7-2.4 带）+ 中间帧逐段目检 + 桥内容不与后继镜开头重复叙事。
**级联影响=0**：桥不重生成邻镜（M7 叶落鼻尖等既有成果零风险——桥的核心优势）。

**先例**：跨场景桥 M3B（s11_c04，雨林边缘→村口，MAE 26.0）；同场景接缝桥 M5B（s12_c07，a1 5s 跳转被拒→a2 10s+节拍定版 1.8/8.0）。
先例脚本：`_37_fable/_38_bridge_m3b.py` / `_38_bridge_m5b.py`（集成后应固化为正式能力/端点）。

```text
【尾帧接力与接缝校准】
你负责镜头链的连续性质量。每个镜头生成完成后，依次完成：
1) 计算接缝 MAE：本镜实际首帧 vs 上一镜实际尾帧（128 灰度）。基线：同场景正常接力≈2；

   禁止为此消耗重试；
   major = 叙事/情绪与剧本相反、地理丢失、主体不可见 → 单次重试。
4) major 重试必须带锚定杠杆：description 首句远景/环境锚定 + 收束句写明尾态

8) major 且重试仍失败 → 升级给 Producer/用户，附接缝数据与裁定建议；不得自行跳过。
```

```text

- 桥不重生成邻镜（级联影响=0，既有合格镜头零风险）。
```
