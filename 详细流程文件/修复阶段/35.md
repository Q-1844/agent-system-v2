## §4 设计

### 4.1 GithubPagesHost（src/core/image_host.py 新增，~70 行）

- 上传：`PUT /repos/{owner}/{repo}/contents/{path}`，body=`{"message","content"(base64),"branch"}`；
  **新文件无需 sha**（唯一命名保证）；409=路径已存在 → 视为成功直接返回 URL（幂等）。
- 命名：`frames/{sha1_8}_{原名}.jpg`——内容寻址、天然唯一、防 Pages CDN 缓存旧内容。
- 返回 URL：`https://{owner}.github.io/{repo}/{path}`（**不是** raw.githubusercontent.com，
  不是 github.com/blob 网页址）。
- **就绪轮询**：上传后 bounded poll GET 返回 URL 直到 200（间隔 5s，上限 180s；
  Pages 构建实测 ~40s）；超时抛错 fail-loud（沿用 ImgbbHost 的「不静默回落」纪律）。
- 重试：API 调用对 5xx/网络错重试 ×3 指数退避（2s/4s/8s）——今晚实测 github.com 路由有抖动
  （curl 000×3 的同一分钟 git push 成功），重试是必要的。
- 依赖：仅 httpx + token；**不需要 git 二进制**。
- 鉴权：`Authorization: Bearer ${GITHUB_TOKEN}`；token 放 `.env`（已在 gitignore），
  config 用既有 `${...}` env 替换机制（同 AGNES_API_KEY）。

### 4.2 config（config/config.yaml）

```yaml
image_host:
  kind: "github_pages"          # imgbb 保留可一键切回
  github_pages:
    owner: "Q-1844"
    repo: "agnes-frame-host"
    branch: "main"
    token: "${GITHUB_TOKEN}"
  imgbb: { api_key: <原样保留>, expiration: 0 }
```

### 4.3 末帧 JPEG 策略（routers/shots.py `_extract_video_end_frame`）

提取 PNG 后、上传前：`PIL` 转 **JPEG q88**（实测 168KB，接力语义只钉位置状态，轻压缩无碍；
boundary 首帧**保持原格式不转**——那是 i2v 开场像素锚，非本节范围）。文件名后缀 .jpg。
注释同步更新：imgbb→Pages。

### 4.4 工厂接线（deps.py）

`get_rehost_host()` 改调 `build_image_host()`（image_host.py 已有 kind 分派）并在其中补
`"github_pages"` 分支；ImgbbHost 分支保留（回退开关）。

## §7 风险与回退

- **github.com API 路由抖动**：重试×3 + 轮询闸门兜底；极端情况 config 切回 imgbb（1 行）。
- **Pages 容量**：站点 1GB 软限 ≈ 累计 6000 张 168KB 帧；按实验节奏（<30 帧/天）半年内无虞；
  届时换新仓库或重写历史（测试仓库允许）。
- **token 泄露**：只放 .env；上传内容仅参考帧（无提示词/日志/密钥——用户已裁定可公开）。
- **回退**：imgbb 线路恢复后 `kind: "imgbb"` 一行即回退；两类并存不互删。
