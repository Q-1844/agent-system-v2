你现在要正式改造 AGNES 项目的“单镜头生成弹窗”。

本任务不是只输出分析报告，而是：
1. 先审计真实代码；
2. 在不破坏现有流程的前提下完成实现；
3. 补齐后端字段、提示词拼接、前端界面和测试；
4. 最终汇报实际修改文件、数据迁移方式和测试结果。

==================================================
一、任务目标
==================================================

将当前单镜头弹窗改造成专业的镜头创作工作台。

弹窗具有：

- 标准模式
- 专业模式

以及三个工作阶段：

- 首帧
- 尾帧
- 视频

重要原则：

1. 标准模式不能像儿童版或极简向导。
2. 标准模式仍然要让用户感受到自己正在使用专业镜头软件。
3. 专业模式只增加真实参与生成的字段。
4. 禁止加入只显示、不保存、不进入 prompt、不进入 API 的空参数。
5. 标准模式和专业模式使用同一个 Shot、同一份项目数据。
6. 切换模式只改变界面显示深度，不能清空或复制数据。
7. 首帧、尾帧和视频必须使用不同的左侧编辑内容。
8. 右侧继续负责候选图片、已选图片和视频预览。
9. 本任务暂不实现：
   - 场景库
   - 场景锚点
   - 连续帧库
   - 长镜头续拍
   - 一个 Shot 多个视频 Segment
   - 新的多视频拼接能力
10. 不要顺手进行无关的全局重构。

10. 点击该提示可切换到专业模式。
11. 不得在两个模式之间自动改写提示词。
12. 不得因为字段在标准模式中隐藏，就不把它加入最终 prompt。

8.1 标准模式字段
------------------------------------------

标准模式显示以下字段：

1. 出场角色
   - 使用公共角色选择。
   - 允许为空。
   - 有角色参考图时，生成接口使用角色参考图。
   - 没有角色时正常走文生图，不报错。

2. 景别
   - 使用选择器。
   - 推荐选项：
     - 大远景
     - 远景
     - 全景
     - 中景
     - 中近景
     - 近景
     - 特写
     - 大特写
   - 保存到现有 shot_size 或兼容字段。
   - 必须进入首帧 prompt。

3. 起始画面描述
   - 中文多行文本。
   - 使用当前 description 字段，避免无意义重复字段。
   - 描述地点、主体和画面中正在发生的状态。
   - 必须进入首帧 prompt。

4. 主体起始状态
   - 新增字段，例如 opening_state。
   - 描述角色姿态、朝向、表情或物体初始状态。
   - 示例：
     “火焰机甲站在废墟中央，右臂自然下垂，身体略微前倾。”
   - 必须进入首帧 prompt。
   - 无角色时可描述主要物体状态。
   - 字段允许为空，空时不拼接占位文字。

5. 机位角度
   - 不再与运镜合并。
   - 新增 camera_angle。
   - 标准预设：
     - 平视
     - 低机位
     - 高机位
     - 俯拍
     - 顶视
     - 仰拍
     - 过肩
     - 主观视角
   - 允许自定义。
   - 必须进入首帧 prompt。

6. 光线与氛围
   - 复用或兼容现有 lighting。
   - 提供预设并允许自定义：
     - 自然柔光
     - 清晨冷光
     - 黄昏暖光
     - 夜景冷光
     - 逆光
     - 侧光
     - 低调光
     - 霓虹光
   - 必须进入首帧 prompt。

7. 英文提示词
   - 标准模式也能看到，但默认折叠。
   - 显示状态：
     - 尚未生成
     - 已生成
     - 已手动修改
     - 内容已变化，建议更新
   - 提供“生成 / 更新提示词”按钮。
   - 复用当前 Agnes 文本模型翻译或提示词生成能力。
   - 不要在用户点击生成首帧时静默调用文本模型。

标准模式不能只剩“画面描述 + 生成”两个输入。

==================================================
十一、尾帧参考图逻辑
==================================================

当前尾帧生成已经以首帧作为图生图参考。

本任务需要增强为：

image_refs 顺序：

1. 已选择的首帧
2. 当前 Shot 选中的角色参考图（如有）
3. 其他当前代码已经支持且明确需要的参考图

规则：

- 第一张图始终是首帧，是场景和构图基础。
- 后续角色图仅用于保持角色身份。
- 提示词必须明确参考图角色：
  - 第一张参考图：场景和起始画面基础
  - 后续参考图：角色身份参考
- 不能让角色参考图取代首帧成为主要构图参考。
- 没有角色时：
  - image_refs 只包含首帧
  - 尾帧仍能正常生成
  - 不返回角色缺失错误
- 角色有 local、无 URL 时，继续复用当前图片接口支持的 Base64 / Data URI 逻辑。
- 不得为了角色参考而强制走视频 ImageHost。
- 不得把首帧重新生成一次后再作为尾帧输入。
- 必须使用用户已经选择的首帧资产。

新增或重构独立函数：

build_last_frame_prompt(...)

建议顺序：

1. 声明以第一张参考图为基础
2. 相对首帧的变化
3. 结束画面
4. 主体结束状态
5. 新增元素
6. 删除元素
7. 结束构图
8. 保持一致选项
9. 自定义保持要求
10. 角色身份参考要求
11. 项目视觉风格

只拼接非空字段。

十二、视频标签
==================================================

视频左侧不能继续显示首帧图片表单。

视频负责定义：

“已有画面如何运动，以及运动过程中什么必须稳定。”

------------------------------------------
12.1 标准模式字段
------------------------------------------

标准模式显示：

1. 输入画面摘要
   - 图生视频：
     [首帧缩略图]
   - 首尾帧过渡：
     [首帧缩略图] → [尾帧缩略图]
   - 只读，不重复选择资产。

2. 主体动作
   - 复用现有 motion，语义明确为主体动作。
   - 示例：
     “火焰机甲短暂停顿后迅速抬起右臂挡在胸前。”
   - 必须进入视频 prompt。

3. 摄影机运动
   - 新增 camera_movement。
   - 不再使用“机位 / 运镜”混合字段。
   - 标准预设：
     - 固定镜头
     - 缓慢推近
     - 缓慢拉远
     - 左摇
     - 右摇
     - 上摇
     - 下摇
     - 横向跟随
     - 向前跟随
     - 轻微环绕
     - 轻微手持
   - 允许自定义。
   - 必须进入视频 prompt。

4. 动作节奏
   - 新增 motion_pace。
   - 预设：
     - 轻微
     - 缓慢
     - 自然
     - 快速
     - 突然
     - 强烈
   - 必须进入视频 prompt。

5. 镜头时长
   - 增加面向用户的 duration 选择。
   - 选项：
     - 跟随配音
     - 约 3 秒
     - 约 5 秒
     - 约 10 秒
     - 约 18 秒
     - 自定义
   - UI 不显示 num_frames。
   - UI 不显示 frame_rate。
   - 后端按当前已有规则转换成合法的 8n+1 帧数。
   - 必须遵守现有 max_frames_for 或等效限制。
   - 不要直接假设所有分辨率都支持 441 帧。
   - 生成完成后显示服务端回读的实际 seconds，不显示理论值冒充实际值。

6. 保持稳定
   - 提供复选项：
     - 角色身份
     - 面部
     - 服装 / 装甲
     - 主体造型
     - 场景布局
     - 画面风格
   - 保存为 video_preserve_elements。
   - 必须进入视频 prompt。
   - 无角色时隐藏角色身份、面部和服装选项。
   - 无角色时仍可选择主体造型、场景布局和风格。

7. 视频英文提示词
   - 标准模式默认折叠。
   - 支持生成 / 更新。
   - 显示是否过期或被手动修改。

------------------------------------------
12.2 专业模式额外字段
------------------------------------------

专业模式增加：

1. 环境运动
   - environment_motion。
   - 示例：
     “烟尘向左翻卷，碎石从地面弹起，远处火光缓慢闪烁。”
   - 必须进入视频 prompt。

2. 动作发生顺序
   - action_sequence。
   - 示例：
     “先停顿半秒，再转头，随后抬起右臂。”
   - 必须进入视频 prompt。

3. 摄影机运动细节
   - camera_movement_detail。
   - 描述方向、速度和结束状态。
   - 必须进入视频 prompt。

4. 首尾帧过渡关系
   - transition_description。
   - 仅 keyframes 模式显示。
   - 示例：
     “从首帧的静止站姿自然过渡到尾帧的格挡姿态。”
   - 必须进入视频 prompt。

5. 自定义稳定要求
   - video_preserve_custom。
   - 与标准模式的保持稳定选项合并。

6. Negative prompt
   - 复用现有 negative_prompt。
   - 只发送给视频 API。
   - 不发送给图片接口。
   - 允许为空。
   - 空时不要发送空字符串参数，遵循当前客户端约定。

7. Seed
   - 复用现有 seed。
   - 只发送给视频 API。
   - 提供：
     - 随机
     - 固定 Seed
   - 随机状态保存为 null。
   - 不要自动写入 0 作为随机值。
   - 固定 Seed 才发送。

8. 视频最终英文提示词
   - 可编辑。
   - 支持 manual override。
   - 结构字段继续保存。
   - 支持按当前字段重新生成。

专业模式不要增加：

- 精确焦距
- 光圈值
- ISO
- 快门角度
- 摄影机三维坐标
- 运动轨道曲线编辑器
- num_inference_steps
- width / height
- frame_rate
- num_frames

- 尾帧不参考首帧直接文生图。
- 无角色时阻止生成。
- 切换模式清空字段。
- 用 localStorage 保存镜头内容。
- 绕过 ProjectStore。
- 破坏旧项目。
