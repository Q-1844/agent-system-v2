# 续跑不依赖无关的图床校验图

## 实际断点

`ink-diffusion-20m-20261105` 已有137个完成视频，但驱动在每次恢复后、启动生产控制器前仍上传一张随机校验图。即使实际输入已公开，这张新图的Pages部署超时也会把恢复任务改成`BLOCKED_PREFLIGHT`，巡检无法继续接棒。仅合成归档模式同样被这次无关写入阻挡。

## 修改

- 新任务保留全新内容地址的图床写入和发布预检，失败仍禁止开始生成。
- 已恢复任务跳过随机校验图。视频handler仍在登记提交意图和调用供应商前，验证本镜实际输入的公开可达性；这项保护没有放宽。
- `finalize_only`跳过校验图，不让本地合成及归档依赖新图的发布。
- 不改Asset字段、创作输入签名、原提交账本或末帧的3次重试及20分钟终试策略。

## 验证

针对新任务成功/失败、恢复和最终归档的五项回归新增通过。与跨日、图床恢复相关的119项回归全部通过。PR #53的真实生产令牌探针已成功，D仓对应Pages运行42330239152也已成功；本修改不改变图床权限或重建逻辑。

最终全量回归及原片续跑结果记录在C仓`docs/HANDOFF_ink_final_20261107.md`。RESTORED或图床部署成功均不代表影片已完成，仍须核验145镜、最终视频、完整归档及COMPLETE状态。
