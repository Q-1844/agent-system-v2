## 5. 能力适用范围（哪些结论只在哪些条件下成立）

- Look 锚定的首帧身份保持力**随风格不同**：水彩/写实 6/8 全符 vs 2D 主片 0/6（观察，未定因）。
- 视频阶段对首帧缺陷有**部分自愈力**（盲测片实测），但不能依赖（残留缺陷清单在案）。
- 机器 Look 审查对写实人像**逐字从严**（10 候选全 needs_fix），人评通道（append-only、不覆盖机器记录）为必要补充——已按既有先例使用并全程留痕。
- `require_new` 对"续作型"同项目 run 会翻搅（说明片 v4 实证），`allow_verified_reuse` 是设计内正解。
- completion 的数字 minCount **不查逐镜覆盖**——W06 修复链是当前有效补位，建议后续加 per-entity 覆盖语义（E 报告 §11）。
