## 5. 失败与偏差清单（如实）

1. **c07 交接方向反转**（1/3 重复）——归因：i2v 对"谁递给谁"的方向语义在双人近景中不稳（提示词明确写明 holder→receiver 仍可反转）。修复选项：根帧重建（交换站位重生成）或换机位（过肩强化方向）。本轮按"真实末态"保留并记录。
2. **ASR partial 2 条**：同音字/繁简（水声→水生、踩→彩），属转写器误差而非生成缺陷；人工试听可终判。
3. 夹具层修复 2 次（全程留痕）：①C 批发现的 Look 参考解析缺陷在 D 批写驱动时预防性规避；②D 驱动首帧 prompt 来源 bug 在运行前修正（未浪费生成）。
4. 双人镜 f0 中位数受同镜另一人干扰（c13），声线对照应以单人镜为准（记录为方法论边界）。
