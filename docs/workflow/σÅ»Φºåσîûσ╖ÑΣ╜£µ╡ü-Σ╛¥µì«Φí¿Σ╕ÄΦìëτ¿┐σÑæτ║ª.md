### 无法证实 / 待后端确认（明确标出，不用虚构填空）

- `AGENTS.md`：仓库根与 `animation-storyboard/` 下均不存在，项目指引为 `CLAUDE.md`（已读）。

## 二、草稿 JSON 契约（workflow_draft_v1）

```jsonc
{
  "schemaVersion": "workflow_draft_v1",
  "projectId": "雨灯归航",              // 项目目录名字符串（projects/ 下同名目录）
  "workflowId": "wf_default",           // 第一版固定 default；后续多工作流再扩展
  "name": "示例：尾帧接力生产链",        // 可编辑，仅草稿标题
  "status": "draft",                    // 第一版恒为 draft（浏览器草稿，非生产执行）
  "createdAt": "2026-10-02T18:30:00.000Z",
  "updatedAt": "2026-10-02T18:35:00.000Z",
  "nodes": [
    {
      "id": "n_a1b2",                    // 节点实例 ID（前端生成，仅草稿内唯一）
      "type": "agent",                   // agent | skill | human_review | boundary_start | boundary_end
      "refId": "director",               // agent=Agent ID；skill=skill_id；review/boundary=null
      "refVersion": null,                // skill 固定其 skill.json version；其余 null
      "label": null,                     // 可选显示别名（人工审核常用）
      "config": {
        "selectedTools": ["shot.create", "shot.generate_videos"],  // agent：获准工具的草稿子集
        "targetSourceNodeId": "n_c3d4",  // review：审核对象来源节点
        "targetArtifact": "storyboard_proposal（分镜结构提案）",      // review：审核对象/产物
        "instructions": "重点核对跨镜接缝",                            // review：审核说明
        "reviewer": "制作人",             // review：审核者（草稿自由文本）
        "note": ""                        // 各类型通用备注
      },
      "position": { "x": 720, "y": 240 }
    }
  ],
  "edges": [
    {
      "id": "e_x1y2",
      "type": "execution",               // execution（执行依赖）| skill_binding（Skill 绑定）
      "source": "n_a1b2", "sourcePort": "out",   // agent/review/start 出口为 out；skill 出口为 bind
      "target": "n_e5f6", "targetPort": "in",    // agent/review/end 入口为 in；agent 另有 bind 入口
      "skillVersion": null,              // binding 线创建时从 Skill 节点钉住的版本
      "contract": {                      // execution 线的产物依据（来自仓库可核实字段）
        "status": "verified",            // verified（有明确契约）| pending_backend（待后端定义）| human_gate（人工审核语义）
        "evidence": "src/agents/assembly.py:98-99；src/sequence/assembly_manifest.py:30-56",
        "upstreamArtifacts": ["冻结快照 shots（shot_id/video_version_id/media_sha256/approved_status）"],
        "downstreamReads": ["assembly.snapshot_read", "read_scopes: shots/versions/snapshot"]
      }
    }
  ],
  "validation": {                        // 导出时附带最近一次前端结构检查结果（保存不写入）
    "ranAt": "2026-10-02T18:35:00.000Z",
    "errors": 0,
    "warnings": 1,
    "issues": [ { "level": "warning", "code": "SKILL_UNBOUND", "message": "…", "nodeId": "n_s9", "edgeId": null } ]
  }
}
```

字段说明与约束：

- `nodes.refId` 必须来自 `src/components/workflow/catalog.ts`（仓库注册表快照）；catalog 里查不到 = 「引用失效」错误。
- `edges.type=skill_binding` 时 `source` 必须是 skill 节点、`target` 必须是 agent 节点；执行依赖线允许 agent/human_review/start → agent/human_review/end，且执行子图必须无环。
- 保存位置：`localStorage["wf_draft::{projectId}::{workflowId}"]`，刷新后恢复；导出为同名 JSON 文件下载。
