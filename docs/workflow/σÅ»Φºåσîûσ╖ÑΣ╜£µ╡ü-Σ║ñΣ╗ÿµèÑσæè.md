## 0.3 Agent 工具语义 + 组件操作手感（2026-10-03 用户反馈）

- **工具语义重定义**（用户原话：针对各自模块的工具都是必有的，额外工具才要选）：右侧面板的 Agent 工具区拆成两段——「核心工具 · 模块自带必有」（注册表全量只读列表，带 ✓，不可勾掉）+「额外工具 · 可选」（当前为空，空态提示"系统后续注册新工具后可在此勾选"；草稿 `config.selectedTools` 仅存额外工具）。Agent 节点徽章常显核心工具数，有额外工具时追加「· 额外 N」。
- **操作手感（对标 Langflow）**：
  - 拖拽：自定义跟随光标的小徽章幽灵（替代整卡半透明镜像）+ 落点 20px 网格吸附（与背景点阵对齐）+ 画布拖入时蓝色虚线高亮框；
  - 点击添加：落到当前视口中心（同样吸附），连续点击按序错位防叠放；
  - 反馈：新节点 160ms 入场动画（缩放+淡入）、组件库卡片 hover 抬升 1px + 阴影、按下回收。
- **真机揪出的两个底层 bug（都会让画布"整体失灵"）**：
  1. `<VueFlow>` 对父级 store 的隐式 adopt（provide/inject）在部分加载时序下失败——父级拿到永远未初始化的孤儿实例，zoomIn/setTransform/screenToFlowCoordinate 全部静默无效（滚轮缩放活着、按钮全死）。修复：显式 store id（`useVueFlow('wf-studio')` + `<VueFlow :id>`），storage 按 id 强制认领。
  2. 页面在后台页签加载时无渲染帧，vue-flow 的 ResizeObserver 不投递，`dimensions` 恒为 0——视口 helper 的初始化门槛（d3Zoom && dimensions）永远不满足，落点换算退化为恒等映射（节点不落在光标下）。修复：挂载后兜底实测视口尺寸并补写 `dimensions`。修复后真机验证：identity 视口与 fit 后（scale 0.29 + 平移）视口下，拖放落点换算均与手算期望逐像素一致。

## 0.2 模块管理操作：删除/解绑/断开/填内容/只读汇报（2026-10-03 用户指令「除了搭建，还应该可以删除等等操作」）

- **助手新动作**（本地规则 + Producer 意图双路径，同一套控制器与校验落图）：
  - 删除：`removeAgent`（级联连线）/ `removeSkill` / `removeReviews`（支持「A 和 B 之间」定位，无定位=全部）/ `removeBoundary`；
  - 解绑 `unbind`（节点保留，可指定 Agent 或全部）、断开 `disconnect`（两站直接执行线）；
  - 填内容 `fillReview`（审核名称/审核说明/审核者——「给审核写说明：重点查运镜」「给导演后的审核的审核者写：制作人」「把导演后的审核改成接缝抽检B」；审核节点卡新增「说明」行）；
  - 只读汇报 `outline`（「看看现在画布」→ 从左到右结构 + 绑定 + 审核者/说明 + 边界与连线统计）。
- **Producer 意图 schema 扩展**：`remove{agents,skills,reviews,boundaries,bindings,connections}` + `fill[{target,after,label,instructions,reviewer}]`；实测 agnes-3.0-flash 还会把 instructions/reviewer 直接放进 review 项——两种形状都支持。**意图执行顺序定为 先删除→再搭建→最后填内容**（实测教训：「删掉后重建」若先插入，会被 `remove.reviews:"all"` 误删新审核）。
- **多意图保护**：本地规则层遇到「删除+搭建/绑定/填内容」跨子句组合时整句让位给 Producer（本地只懂一半会悄悄漏做）；离线时面板如实说看不懂。
- **画布快捷操作**：四类节点悬停出现 ✕（与面板「删除此节点」等效，级联连线）；连线双击直接删除（toast 提示）。实现为 `useNodeDelete` 注入控制器，节点组件零事件透传。
- **回复诚实性**：失败动作不再计入主句（修复「已删掉导演」与「画布上没有导演的节点」同屏自相矛盾）；删除/解绑附数量明细（「已移除 N 个审核节点」）。
- **真机电池**（7777 真页面 + 真后端）：填说明/审核者/名称三连 ✓、解绑（修复 `解除…绑定` 不相邻没被识别的漏洞）✓、断开连线 ✓、画布汇报 ✓、两站之间删审核/删全部/删节点/删边界 ✓、重复删除诚实报错 ✓、悬停 ✕ 删节点 ✓、双击删线 ✓、**Producer 组合意图（删 4 道审核→重建 1 道→填说明与审核者）一次正确落图 ✓**。typecheck：workflow 模块 0 错误。

## 0.1 文本模型全局切换 agnes-3.0-flash + 助手加固（2026-10-03 用户指令）

- **模型切换**：`config/config.yaml` `agnes.models.text: agnes-2.5-flash → agnes-3.0-flash`（全部 Agent 的文本调用生效；Profile 的 reasoning_model 是 config 镜像，自动跟随）。
  切换前实证：`GET /v1/models` 在列 `agnes-3.0-flash`；function-calling 探针通过（tool_calls 正确返回，1.2s）。切换后实证：后端日志 8 次调用全部 `model=agnes-3.0-flash`；`/api/agents/profiles` 全部 agnes 文本档案显示 3.0。
  **不在范围**：Director 的 Vision 审查（`director_vision_review.py` 显式 `VISION_MODEL=agnes-2.5-flash`，图像判定探针定版）保持不变。
  测试：`tests/test_agent_model_switch.py` 的配置钉死断言改为「跟随 config 且必须 agnes- 系」语义断言。
- **助手解析器修复（真机压测发现）**：`parseLocal` 重写为组合式解析（链+审核+绑定同句共存、绑定动词按子句提取防跨句误绑）时，函数末尾误留 `return []` 导致恒空——已修为 `return actions`；「立起来」误触发已防。修复后本地规则层 1 秒内正确处理组合指令。
- **助手强化**：意图 schema 明确「ref 外职责不得发明新 Agent，在 note 说明归入哪个现有 Agent」（实测：配音/旁白被正确归入 assembly 而非虚构）；`withBoundary` 仅在用户明确要求时为 true；每条后端回复的 meta 显示实际模型，出现真实委派任务引用（linked_task_ids）时大字警告。
- **压测记录**（新规则+3.0 模型）：复杂组合建链（本地规则 1s）/ 插入语义「在装配之前加两道人工把关」（Producer 4s 正确插入 director↔assembly）/ 未知 Agent（不虚构，诚实归入）/ 歧义规划问句（合理解析、重复如实提示）/ 重复绑定（本地+后端双路径诚实）/ 全程 linked_task_ids=0（零执行副作用）。

## 0. 搭建助手（右侧对话框，二次增量）

- 位置：工作流页最右侧 296px 对话栏，顶栏「搭建助手」开关（≥1280px 默认展开）。
- 两层解析，诚实标注：**本地规则层**即时处理常用指令（标准链 / A→B 链 / 在 X 与 Y 之间插 n 道审核 / 绑定 Skill / 加单节点 / 清空 / 检查，中文关键词+防误触发）；**后端层**把规则看不懂的自由表述经既有 `agentTurn` 端点交给 Producer（真实大模型）解析为「意图 JSON」（chain/reviews/bindings/withBoundary），再由本地按真实注册表物化为节点与连线——助手专用 producer 会话按项目缓存隔离。

- 真机测试：清空画布 / 标准链（7 节点 6 线）/ 插两道审核（重连线）/ 绑定接力校准 / Producer 路径（长自由句 7 秒回合，理解+落图+重复绑定诚实提示）/ 离线回退（Failed to fetch 明示）/ 未保存守卫 / 刷新恢复，全部通过。

## 6. 尚待后端确认的真实契约（下一阶段接口）

1. 逐对 Agent 产物契约：目前仅 director→assembly（冻结快照/manifest v1 字段）、producer 委派 envelope、specialist→producer AgentStructuredResult 三类可核实；其余连线标 `pending_backend`，需后端为每对上下游声明 canonical 的 `upstreamArtifacts[] / downstreamReads[]`。
2. 人工审核的任务语义：暂停/恢复/驳回重发机制（页面首版语义=通过→继续、驳回→停止留意见，未伪装自动返工）。
3. Skill 绑定是否扩展到 `assembly`（`skill_system/models.py:VALID_AGENT_IDS` 现不含）。
4. 草稿持久化 API 与「运行」提交协议（页面「运行」按钮保持禁用，标注「待后端接入」）。
5. Skill 无 REST 查询端点：前端目录为 skill.json 快照，新增正式 Skill 需同步 `catalog.ts`（或等后端提供端点后改为运行时拉取）。
