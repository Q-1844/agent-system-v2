测试：P48_E_Proc（photoreal，单主体手部流程《划火柴点蜡烛》，无对白无旁白）：
- s01_c01 = 10s 逐秒分拍完整因果链；s01_c02 = 8s 接续镜。run_c435abd48030 + W06 干净重跑 run_230134e317e5。
- **判定①时长控制达标**：10.1s / 8.0s 精确做满 target_duration_s（2.5 契约 4-12s，管线直通）。
- **判定②逐秒分拍=序列完整、秒级不精确**：两版视频动作链均按分拍顺序发生，但秒级对齐松（首版点火 ~s4-5 而非 1-2s；干净版引燃落到 s10 片尾而非 6-8s）——视频模型把逐秒分拍当"动作序列清单"而非"硬拍点"。对创作的含义：按秒写动作能保证"该发生的都发生"，不能保证"在第几秒发生"；要卡点需要靠剪辑而非生成。
- **判定③单主体流程片质量好**：photoreal 手部+物件无人物，无伪影，风格稳定——用户"这类视频继续测"的方向得到支持。

- A 组长度 A/B：短 prompt（70 字）属性 2/2 全符；2000 字长 prompt（agnes-3.0-flash 自写，要素齐全但被埋在 600-900 字位置）属性 0/2 全丢（黄雨衣→浅蓝、双马尾→短发、手持灯笼→挂墙）——图像模型属性跟随随长度衰减，但氛围渲染更丰富。
- B 组多人物纯 t2i：互动构图/递接方向 3/3 正确；单角色属性漂移（双马尾→单马尾、背带裤颜色错）。

**批 02（P49_IMG_02，photoreal，360 张，零失败）**
- 3 分镜（雨夜递灯笼/共伞同行/灯下对视）× 4 手法 × 30 张：T1 短prompt直出 / T2 设定图i2i / T3 场景底图i2i / T4 模型长prompt（601-1121 字）。
- 分类预览页：`projects/P49_IMG_02/output/preview.html`（按分镜→手法→30 张网格）。
- API 约束发现：图像接口 seed 仅接受 -1~999。
- 接续边界：夹具项目的 multi+prev_tail 尾帧接力被生产绑定 gate 拒绝（无 SceneInstance/Look），真接力需完整 W09 上下文。

**用户终审裁定（2026-10-07）**：
- **质感 T1（短 prompt 直出）最好**；T2/T3/T4 均不如。
- **整体效果并不好**——图片优先迭代停止。
- 结论归档：写实人像的"质感"是当前图像模型的硬上限，短直出反而最干净；长 prompt/i2i 提升氛围与服装绑定，但损失质感且发型等细节仍不稳。首帧路线在当前模型下无法达到用户要求的质感标准——视频与图片生成测试均以"模型能力上限"为由暂停，待模型升级或更换 provider 后重启。

**图片 skill 缺口确认**：Skill 专区无图片生成专用 skill（仅两个视频链 skill）。因图片路线暂停，skill 沉淀一并挂起；方法论素材（设定图先行/i2i 锁定/六维度审查/本轮 A-B 结论）已在本节留档，重启时可作 skill 草稿底稿。
